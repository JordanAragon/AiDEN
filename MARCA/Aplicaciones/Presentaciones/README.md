# Presentaciones

## Plantilla

`plantilla-presentacion-aiden.pptx` (PowerPoint, 16:9), con tema AiDEN (colores y fuentes) y cinco diseños:

| Diseño | Uso |
| --- | --- |
| `PORTADA_TEXTOS` | Portada: logo a color, título y subtítulo sobre Paper |
| `SECCION_TEXTOS` | Separador de sección: número en Lime y título sobre Forest |
| `CONTENIDO_TEXTOS` | Título + contenido |
| `CONTENIDO` | Solo marco (pie, logotipo, número): para cifras, gráficas o imágenes |
| `CIERRE` | Logo centrado |

Las diapositivas de ejemplo muestran cada diseño; bórralas o duplícalas.

## Reglas

- Logo a color (A) en portada y cierre; logotipo pequeño en el pie de las diapositivas de contenido.
- Una idea por diapositiva; el título dice la conclusión.
- Máximo cinco viñetas cortas; cifras con fuente (módulo de AiDEN y periodo).
- Gráficas nativas de PowerPoint con los colores del tema.
- Para presentaciones institucionales en blanco y negro, cambia el logo por la versión monocromática.
