# Fotografía

Dirección visual propuesta:
- viveros e invernaderos reales;
- plantas y cultivos;
- trabajadores y procesos agrícolas;
- tecnología aplicada al campo;
- sensores y monitoreo;
- iluminación natural;
- contexto latinoamericano/colombiano cuando sea pertinente.

Evitar fotografías de stock excesivamente corporativas o imágenes agrícolas genéricas sin relación con el producto.
