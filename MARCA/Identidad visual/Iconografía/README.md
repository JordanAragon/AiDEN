# Iconografía

La identidad debe utilizar iconos simples, redondeados y consistentes con la geometría del isotipo.

La implementación actual puede seguir usando Lucide, pero deben normalizarse:
- grosor;
- tamaño;
- color;
- uso en botones;
- estados;
- relación icono/texto.

No crear una segunda familia de iconos sin necesidad.
