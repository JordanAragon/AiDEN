# Roles

Los tres roles comparten una sola marca. Se distinguen por un acento en el encabezado de página (barra bajo el título, `src/estilos/sistema-aiden.css`), no por paletas ni logos propios.

| Rol | Acento | Color |
| --- | --- | --- |
| Administrador | Moss | `#718b58` |
| Supervisor | Forest | `#0b2b1b` |
| Operario | Lime | `#d9ea73` |

No se crean sub-marcas, logos ni nombres por rol.
