# Estados

Colores funcionales del producto (`DESIGN.md`). Comunican estado; no reemplazan a la paleta de marca.

| Estado | Color (claro) | Fondo suave | Uso |
| --- | --- | --- | --- |
| Éxito / acción | `emerald-700` | `emerald-50` | Confirmaciones, botón principal |
| Advertencia | `amber-700` | `amber-50` | Valores fuera de rango que no bloquean |
| Error | `red-600` | `red-50` | Fallos, incidencias críticas |
| Información | `sky-700` | `sky-50` | Avisos neutros |

Reglas:

- El color nunca es la única señal: siempre con ícono o texto («Crítica», «Pendiente»).
- Contraste mínimo 4,5:1 en ambos modos.
- Mensajes con el tono de `Identidad verbal/`: claros y sin culpar.
