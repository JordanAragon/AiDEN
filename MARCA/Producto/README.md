# Producto

La identidad de marca debe traducirse al producto sin romper el sistema visual existente.

## UI
Conservar la estructura y reglas documentadas en DESIGN.md.

## Componentes
Los componentes existentes son la base; las nuevas piezas deben reutilizarlos.

## Roles
La diferenciación por roles debe seguir siendo parte de una misma marca y no convertirse en sub-marcas.

## Estados
Success, warning, error e info deben mantener contraste y jerarquía funcional sin desplazar la paleta principal.

## Data visualization
Producción, Ambiental, Calidad, Costos y Reportes necesitan reglas comunes para series, líneas, áreas, etiquetas, tooltips y accesibilidad.
